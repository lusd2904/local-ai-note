# Local AI Note - 智能笔记与智库工作站

## 项目概述
Local AI Note 是一款专为隐私与效率打造的本地私有化 AI 智能笔记与智库工作站。数据完全物理留存在本地，结合现代化所见即所得编辑器、AI 智能助手与深度内容解析，为您提供安全、高效的知识管理与生产力体验。

## 🌟 核心功能一览

- 📝 **现代化富文本与 Markdown 所见即所得编辑**：Tiptap 驱动，支持系统截图（Cmd+Shift+4）秒级 Cmd+V 粘贴渲染并持久化存储、支持 Word (.docx) 一键导出与本地备份。
- 🔒 **笔记二次验证与密码锁定**：重要笔记支持一键加锁，PBKDF2 加盐哈希加密，列表卡片强制脱敏保护，会话级解密内存隔离，彻底杜绝敏感凭证泄露。
- 🎙️ **语音录音工坊 (Audio Studio)**：高保真音频采集，波形可视化，Whisper 语音转写，AI 自动提炼核心结论与待办清单 (Action Items)，一键转入笔记。
- ✨ **AI 智能扩写与快捷算子**：一键深度扩写（根据简略提纲检索补充行业背景与权威数据）、智能摘要、专业润色、标签自动提取、Mermaid 思维导图一键生成。
- 🤖 **独立 AI 智能咨询助手**：全尺寸沉浸式咨询工作区，支持 Claude 3.7 (Extended Thinking)、DeepSeek R1、OpenAI GPT-4o、Ollama 离线多模型自由切换，咨询结果一键沉淀为笔记。
- 🌐 **官方网页版 AI 深度内嵌**：字节跳动「豆包」与「DeepSeek」官方网页版原生集成，基于 macOS 原生顶级 WKWebView 架构，登录态系统级持久化存储，彻底告别重复登录与 iframe 跨域拦截。
- 📂 **无限多级笔记本与标签系统**：树状目录无限层级、递归删除与移动、收藏夹、废纸篓与暗黑模式支持。
- 🍏 **原生 macOS 桌面客户端 (`Note.app`)**：Swift + WebKit 构建，沉浸式毛玻璃无边框窗口、独立 Dock 图标、原生麦克风权限支持。
- 📱 **iOS 独立端与局域网免公网双向同步**：iOS 端完全脱离 macOS 独立运行，数据物理存储在 iPhone 本地沙盒；支持在同一 Wi-Fi 局域网下通过动态二维码/PIN 码一键配对，秒级双向增量数据同步。
- 🔗 **块级双向链接与反向引用 (Backlinks)**：支持 `[[双链]]` 快速关联已有笔记，正文内链一键跳转，底部抽屉自动汇总反向提及与上下文摘要。
- 🪐 **交互式 2D 力导向知识关系图谱 (Graph View)**：原生 60fps Canvas 物理模拟引擎，星空全景漫游、手势/滚轮缩放、节点拖拽聚类与点击定位。
- ⚡️ **闪念速记灵感流 (Memo Stream)**：随时捕捉碎片灵感与截图，自动提取 `#标签`，支持多选一键批量汇聚整理为结构化正式长笔记。
- 🟩 **GitHub 风格 365 天知识产出打卡热力图 (Activity Heatmap)**：量化每日记录与字数沉淀，活跃天数与连续打卡统计，激发持续记录习惯。

- **本地沙盒物理存储 (IndexedDB 引擎)**：iOS 端彻底脱离 macOS 服务端独立运行，所有笔记增删改查、富文本编辑、录音、标签、分类完全保存在 iPhone 本机沙盒中，离线无网状态下秒开秒存。
- **macOS 全功能 100% 对齐**：支持 Tiptap 所见即所得富文本、表格、4 风格润色、AI 续写、思维导图、5 大模型官方内嵌与二次密码验证加锁保护。

- **iOS Native Xcode 工程**：在 `ios/NoteApp/` 目录下提供 Swift + WebKit + AVFoundation 独立移动端工程与麦克风、相机、局域网网络权限配置。
- **iOS 移动端界面深度适配**：集成 iOS Safe Area（顶部刘海/灵动岛与底部 Home Indicator 留白）、移动端响应式抽屉与触控友好交互。

### 2. ⚡️ 同一 Wi-Fi 局域网配对与双向原子数据同步 (LAN Sync)
- **免公网服务器，点对点受信任配对**：Mac 端自动检测局域网直连 IP 并生成高分辨率配对二维码与 6 位安全 PIN 码，iPhone 扫码或输入 PIN 码即可完成设备双向握手。
- **毫秒级增量双向同步 (Two-Way Sync)**：基于 `updated_at` 时间戳差异比对算法，仅推送与拉取变更增量数据，单次原子请求完成双向数据合并与智能冲突仲裁。
- **废纸篓与软删除同步**：修复软删除同步机制，两端删除与恢复操作毫秒级对齐。
- **快捷控制中心**：侧边栏左下角新增「⚡️ 多端同步」常驻入口，实时展示连接状态、最后同步时间与同步结果统计。

### 3. 🔒 系统性功能与安全审计深度加固 (18 项全量修复)
- **Token 防泄漏机制**：`/api/sync/info` 接口与二维码 Payload 彻底移除 Token 暴露，Token 仅在配对握手成功后加密返回。
- **防暴力破解与配对码动态轮换**：配对码升级为 6 位纯数字，每 5 分钟自动轮换过期；连续 5 次配对失败自动锁定 60 秒并强制重置配对码。
- **密码哈希网络传输隔离**：所有同步与拉取接口的 `password_hash` 字段统一过滤为 `null`，避免 PBKDF2 哈希暴露于网络，密码加锁各端独立管理。
- **IndexedDB 多 Store 单事务原子性**：修复 `bulkApplySyncData` 跨表写入逻辑，所有 ObjectStore 统一在单个原子事务中提交，彻底杜绝数据不一致。
- **CORS 局域网白名单限制**：CORS 由全开放 `*` 改为正则严格匹配本地与私有局域网 IP 段（`192.168.*`, `10.*`, `172.16-31.*`），彻底防范公网恶意网页 CSRF。
- **DoS 流量防护**：同步接口增加单次最大 500 篇笔记 / 100 个笔记本的数据量限制。
- **iOS ATS 权限精细化与内存泄露修复**：禁用全局 `NSAllowsArbitraryLoads`，改用 `NSAllowsLocalNetworking` 仅放行局域网 HTTP；使用弱引用代理修复 WKScriptMessageHandler 循环引用内存泄漏。
- **恢复 Favicon 视网膜图标与 UUID 安全生成**：恢复 `<link rel="icon">` 网页与 macOS 客户端图标，UUID 生成升级为浏览器原生 `crypto.randomUUID()`。

## 🚀 0819 V2 迭代更新日志 (安全加固与交互升级)

### 1. 🔒 企业级密码哈希与核心安全加固
- **PBKDF2-HMAC-SHA256 加密升级**：密码算法全面升级为 **600,000 次安全迭代** 与 16 字节随机盐（符合 OWASP 2023 行业安全标准），彻底抵御 GPU 暴力破解与彩虹表。
- **平滑向后兼容与自动无感迁移**：数据库现有笔记自动兼容旧格式，用户在下次输入密码验证通过后自动静默升级为 PBKDF2。

- **克隆笔记密码隔离**：克隆后的副本笔记默认解除加锁状态，杜绝密码交叉共享与越权查看风险。

## 🛠 快速启动与部署指南

- **方案 1：Docker Compose 一键启动 (推荐)**
  ```bash
  docker-compose up -d
  ```
- **方案 2：macOS 原生桌面应用启动**
  ```bash
  ./run.sh app
  # 或安装到应用程序：
  ./run.sh install-app
  ```
- **方案 3：本地源码开发环境启动**
  ```bash
  # 后端
  python main.py
  # 前端
  npm run dev
  ```
