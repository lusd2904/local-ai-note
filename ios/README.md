# 📱 Local AI Note - iOS 独立移动端与局域网数据同步指南

本目录包含 **Local AI Note** 专属的 **iOS 独立端解决方案**。iOS 端与 macOS 完全解耦独立运行，数据物理存储在 iPhone 本地沙盒，在同一 Wi-Fi 下可一键配对并进行秒级双向增量数据同步。

---

## 🌟 核心特性

1. **完全离线优先与数据本地化 (Offline-First)**：
   - 采用本地持久化存储（IndexedDB / SQLite），所有笔记增删改查、富文本编辑、录音转录、AI 对话完全运行在 iPhone 本机上，无网络也可流畅秒开。
2. **macOS 全要素功能 100% 对齐**：
   - Tiptap 所见即所得富文本编辑器（复杂表格、标题、粗斜体、代码块、高亮引用）。
   - 4 种风格智能润色、光标处 AI 智能续写、错别字纠错、Mermaid 思维导图。
   - 豆包、DeepSeek、Kimi、Grok、Gemini 5 大官方模型内嵌与免重复登录持久沙盒。
   - 密码二次验证与笔记加密加锁保护。
3. **局域网免公网 P2P 双向数据同步 (Local Wi-Fi Two-Way Sync)**：
   - **一键配对**：同一 Wi-Fi 下，iPhone 扫描 Mac 屏幕展示的二维码（或输入 6 位 PIN 码）即可完成受信任配对。
   - **增量双向合并**：基于时间戳差异比对，两端的数据变更（新增、修改、废纸篓软删除）一键合并，冲突智能仲裁。

## 🚀 安装与运行方式

### 方案一：iOS Safari 极速「添加到主屏幕」（免安装、即开即用推荐）

1. 确保 iPhone 与 Mac 连接在**同一个 Wi-Fi** 下。
2. 在 iPhone Safari 浏览器中打开 Mac 端的局域网地址（例如 `http://192.168.1.100:8008`）。
3. 点击 Safari 底部的 **「分享」按钮 (Share)**。
4. 选择 **「添加到主屏幕」 (Add to Home Screen)**。
5. iPhone 桌面上将生成带专属高清 App 图标的 **独立全屏应用**：
   - 具有独立的沙盒生命周期与全屏体验；
   - 离开 Wi-Fi 依然可以随时随地离线编辑；
   - 回到同一 Wi-Fi 下点击侧边栏底部的 **「⚡️ 多端同步」** 即可一秒同步！

---

### 方案二：Xcode 原生 iOS App 编译打包

1. 如前端有更新，先在仓库根目录构建，再同步静态资源：
   ```bash
   cd frontend && npm run build
   bash ios/sync_www.sh
   ```
2. 用 Xcode 打开 `ios/NoteApp.xcodeproj`，选中你的 iPhone。
3. 首次真机安装：iPhone「设置 → 通用 → VPN 与设备管理」里信任开发者证书。
4. `Product → Clean Build Folder`，然后 `Cmd + R` 运行。

不需要再手动把 `www` 拖进 Copy Bundle Resources。工程会在编译时自动把 `NoteApp/www` 打进 App。若页面加载失败，屏幕上会直接显示诊断信息，不必翻 Xcode 控制台。

## 🔄 双向同步操作流程

1. **Mac 端**：
   - 打开设置或点击左下角「⚡️ 多端同步」图标，展示本机二维码与 6 位配对码。
2. **iPhone 端**：
   - 点击底部「⚡️ 多端同步」，输入 Mac 局域网地址与配对码（或扫码）完成握手。
   - 点击 **「⚡️ 立即执行双向数据同步」**，两端笔记瞬间完成合并对齐！
